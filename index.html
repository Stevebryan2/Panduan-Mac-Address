Cara Cek MAC Address & Model Name

Pilih jenis perangkat di bawah ini. Klik pada gambar panduan untuk memperbesar tampilan.

1. Melihat Model Name iPhone

  1. Buka aplikasi Settings (Pengaturan).
  2. Pilih menu General (Umum) → About (Mengenai).
  3. Lihat pada baris Model Name (Nama Model) (contoh: iPhone 15 Pro).

Tempat Screenshot Model iPhone

images/Model Name Iphone.png

2. Melihat MAC Address (Wi-Fi Address)

  1. Masih di menu Settings → General → About.
  2. Scroll ke bawah dan cari bagian Wi-Fi Address (Alamat Wi-Fi).
  3. Salin 12 karakter kode tersebut (contoh: A1:B2:C3:D4:E5:F6).
Penting untuk Pendaftaran Wi-Fi: Jika MAC Address didaftarkan ke jaringan kantor/kampus, matikan fitur Private Wi-Fi Address (Settings → Wi-Fi → klik ikon (i) di Wi-Fi terkait → Private Wi-Fi Address: Off).

1. Melihat Model Name Android

  1. Buka aplikasi Settings (Pengaturan).
  2. Scroll ke paling bawah dan pilih About Phone (Tentang Ponsel).
  3. Lihat bagian Model atau nama perangkat di bagian atas layar.

Tempat Screenshot Model Android

images/android-model.png

2. Melihat MAC Address

  1. Buka Settings → About Phone (Tentang Ponsel).
  2. Pilih menu Status Information (Informasi Status) atau All Specs.
  3. Scroll ke bawah dan lihat bagian Device Wi-Fi MAC address.
Catatan Privacy (Randomized MAC): Pastikan menyalin Device/Phone MAC Address. Di pengaturan Wi-Fi tujuan, ubah bagian Privacy dari Use randomized MAC menjadi Use device MAC.

1. Melihat Model Laptop Windows

  1. Tekan tombol Win + R di keyboard.
  2. Ketik msinfo32 lalu tekan Enter.
  3. Cari baris System Manufacturer (Merek) dan System Model (Model lengkap laptop).

Tempat Screenshot System Information (msinfo32) Windows

2. Melihat MAC Address (Physical Address)

Cara 1: Lewat Settings
  1. Buka Settings → Network & internet → Wi-Fi.
  2. Klik Hardware properties.
  3. Cari baris Physical address (MAC).

Foto 1: MAC via Settings

images/windows-mac-1.png
Cara 2: Lewat Command Prompt
  1. Tekan Win+R, ketik cmd → Enter.
  2. Ketik ipconfig /all → Enter.
  3. Lihat Physical Address di bagian Wi-Fi.

Foto 2: MAC via CMD

1. Melihat Model Name MacBook / Mac

  1. Klik ikon Apple () di pojok kiri atas layar.
  2. Pilih About This Mac (Mengenai Mac Ini).
  3. Nama model beserta tahun rilis dan chip akan langsung terlihat di jendela yang muncul.

2. Melihat MAC Address (Wi-Fi Address)

Cara Cepat (Menu Bar)

  1. Tahan tombol Option (⌥) di keyboard.
  2. Klik ikon Wi-Fi di menu bar kanan atas.
  3. Lihat baris Address di menu dropdown.

Lewat System Settings

  1. Buka System Settings → Wi-Fi.
  2. Klik Details... di Wi-Fi yang terhubung.
  3. Pilih tab Hardware → lihat MAC Address.
